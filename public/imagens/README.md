# Imagens do projeto

Coloque as capturas de tela nesta pasta usando estes nomes:

- `dashboard.webp`
- `pacientes.webp`
- `sessoes.webp`
- `financeiro.webp`

Os placeholders da landing page são substituídos automaticamente quando cada arquivo existir.

Para preservar a nitidez sem deixar a página pesada, prefira imagens em proporção 16:10, com largura entre 1400 e 1800 px e formato WebP.
