# Product

## Platform

web

## Stack

React com TypeScript e Vite, conforme solicitado pelo usuário. A landing page é um projeto independente dentro de `pacientplans-lp`.

## Users

- Usuário do sistema: profissionais de psicologia que organizam pacientes, sessões e finanças da clínica.
- Visitante deste portfólio: professor orientador avaliando o projeto de estágio.

## Product Purpose

O PacientPlans centraliza a rotina administrativa de uma clínica de psicologia. O portfólio apresenta o problema, a solução, os casos de uso, o cronograma, a documentação e as evidências do trabalho desenvolvido.

## Positioning

O sistema reúne, em uma única rotina autenticada e isolada por profissional, o acompanhamento de pacientes, sessões, reposições, cobranças e relatórios.

## Operating Context

O profissional acessa um painel diário, mantém os dados dos pacientes, agenda e acompanha sessões, controla pagamentos e consulta indicadores. Um administrador cria os acessos dos profissionais sem visualizar dados clínicos ou financeiros.

## Capabilities and Constraints
