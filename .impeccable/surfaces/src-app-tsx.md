# Landing page do portfólio

- Escopo: página única React em `src/App.tsx`.
- Modo: Persuade.
- Público: professor orientador avaliando o projeto de estágio.
- Trabalho: compreender rapidamente a proposta, verificar a implementação e acessar as evidências.
- Ação principal: explorar o projeto; ações secundárias: abrir documentação, vídeo e relatório quando forem adicionados.
- Prova: funcionalidades verificadas no código, stack, casos de uso, cronograma e espaços preparados para capturas reais.
